## Fix Details

### Fix 1 — Lockfile regeneration

`apps/web/package.json` was updated to `@evan-school/*` and added `@clerk/nextjs`,
but `pnpm-lock.yaml` was not re-generated. CI's `--frozen-lockfile` flag will fail
until the lockfile reflects the current `package.json` files.

**Action:** Run `pnpm install` (without `--frozen-lockfile`) on Node 22 and commit
the updated `pnpm-lock.yaml`.

### Fix 2 — `zod` dependency bucket

`packages/config/src/index.ts` imports `zod` at runtime. With `zod` in
`devDependencies`, it is installed in the workspace (pnpm installs all devDeps) and
TypeScript can resolve it, but the package.json contract is wrong: any consumer that
installs `@evan-school/config` as a production dep without devDeps would lack `zod`.
Moving it to `dependencies` is the correct semantic and avoids future breakage.

**Action:** Edit `packages/config/package.json`. After this change, re-run
`pnpm install` to update the lockfile's importer entry for `packages/config`.

### Fix 3 — Root package name

The root `package.json` still carries `"name": "tgh-template"`. NX uses this for
display and workspace identity. This is a correctness fix, not a build blocker.

**Action:** Edit `package.json`, change `name` to `evan-school`.

### Fix 4 — Constitution

The template-generated constitution had PLACEHOLDER project identity fields.
These are now filled in (see this session's constitution update).
